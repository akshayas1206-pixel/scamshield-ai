SCAMSHIELD AI - FRESH STARTER

WHAT THIS IS
A small Flask website prototype with a message checker and a basic visible-URL pattern checker.
It uses simple rules, not a trained AI model. It can be wrong; do not treat results as proof a message or link is safe.

WINDOWS SETUP
1. Install Python 3.11 or newer from https://www.python.org/downloads/
   During installation, tick "Add python.exe to PATH".
2. Extract this ZIP to a folder you can find, such as Desktop\ScamShield_AI_Fresh.
3. Open that folder in File Explorer.
4. Click the address bar, type cmd, and press Enter.
5. In the command window, type:
   py -m venv .venv
   Press Enter.
6. Then type:
   .venv\Scripts\activate
   Press Enter.
7. Then type:
   py -m pip install -r requirements.txt
   Press Enter and wait for it to finish.
8. Then type:
   py app.py
   Press Enter.
9. Open your browser and go to http://127.0.0.1:5000

To stop the local website, click the command window and press Ctrl+C.
This runs locally on your laptop; it is not published online yet.
